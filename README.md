# SALAZAR Innovation

Proyecto de landing page para SALAZAR Innovation.

## Estructura

- `salazar-inicio.html`: archivo principal de la página.
- `assets/css/styles.css`: estilos de la interfaz.
- `assets/js/main.js`: lógica de interacción y comportamiento.
- `assets/images/`: imágenes y logos del sitio.

## Cómo abrirlo

1. Abre `salazar-inicio.html` en tu navegador.
2. Si quieres servirlo localmente con un servidor, puedes usar cualquier servidor estático simple.

## Observaciones

- La estructura ya quedó separada para facilitar mantenimiento.
- CSS y JS quedaron fuera del HTML para que sea más fácil de leer y editar.
